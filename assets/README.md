# Icons

App icon: the koma mascot (the white-1024 variant from koma-landing `public/brand/`), kept as `icon-source.png`.
Regenerate the whole set with `python3 assets/gen-icons.py assets/icon-source.png`.

`gen-placeholder-icons.py` is the obsolete winking-face placeholder generator; do not use it for the shipped icon.

`gen-icons.py <source.png>` resizes any square PNG into the same set.
