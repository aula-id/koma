# Web search setup

## GUI
Open Settings → Web search. Built-in DuckDuckGo needs no key. Firecrawl, Tavily and Exa require their own API keys. Enter the key and use the displayed activation control; enabled providers show their active state. Configuration is stored for the installation. Do not confuse the search provider with the chat model provider. Internet mode controls how the agent searches; it does not supply a missing search credential.
## TUI
/internet toggles simple/full search mode; /internet simple and /internet full select explicitly. Ctrl+E also changes internet mode as listed by the keyboard registry.
## Recovery
Check provider selection, configuration scope and credential presence when search fails. The Help assistant can explain setup but cannot set keys or test terminal commands for you.
