# Settings and appearance

## GUI
Open Settings with the gear. Sections include Web search, Account, Appearance, Session, Sidebar, Skills, LSP, SSH keys and Computer. Sidebar settings reorder or hide activity items; overflow contains items that do not fit. Help, Notifications and Settings remain fixed. Session settings apply to the attached session; installation settings apply locally. Review each control's scope before saving.
## TUI
/settings (alias /config) opens configuration; /help lists registered shortcuts. /security controls the security daemon.
## Recovery
If a panel is hidden, make it visible in Sidebar settings or use overflow. LSP needs a server on PATH or a configured server entry. Users perform all configuration changes themselves.

## UI scale

In Settings → Appearance, choose 1×, 1.5×, 2× or 2.5× to scale the entire interface: text, icons, spacing, controls, code editors and terminals. Designer and diagram canvas content keep their existing visual scale; their toolbars and property panels follow the UI scale. 1× uses the original sizes. Changes apply immediately and persist locally across sessions and remote connections. If native zoom fails, the previous selection remains active and Settings shows an error. This GUI preference does not change TUI settings, authored design or diagram dimensions, exports, or the separate computer-preview window.
