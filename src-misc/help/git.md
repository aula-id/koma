# Source control and Git

## GUI
Source Control requires a Git repository. Inspect status and diffs before staging and committing. Branch, remote, fetch/pull/push and conflict workflows use the selected repository. Select the correct root in a multi-repository workspace. Non-Git file diffs may use a session first-touch baseline rather than Git. Unsaved editor changes and Git working-tree changes are separate.
## Recovery
Check the active repository, branch, authentication and operation result. Resolve conflicts yourself and use the displayed continue/abort controls. Never retry commit, reset, merge, revert or deletion merely because a popup expired. Help cannot commit or run Git commands.
