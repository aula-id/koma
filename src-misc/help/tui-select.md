# TUI /select

## TUI /select
Dump full history to terminal for native copy (viewport is already selectable).

Outputs the entire conversation to the terminal so you can select and copy it using your terminal's native selection. This is useful when you need to copy a large code block or output that's hard to select in the chat UI.

Use /help for the registered command and keyboard reference. This is a TUI slash command; the GUI uses its corresponding controls.
