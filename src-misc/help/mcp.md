# MCP servers

## GUI
MCP manages server definitions: add, edit, enable and remove. Server tools become available after successful connection. Inspect the server transport and required command, endpoint or environment settings. Configuration alone does not prove the server is running.
## TUI
/mcp opens the server dashboard with live tool counts.
## Recovery
Check server availability, command installation, endpoint and required configuration. Do not send environment secrets to Help. Unknown third-party server behavior is not documented by this built-in reference.
