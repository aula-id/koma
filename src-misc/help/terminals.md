# Terminals and shell jobs

## GUI
Integrated terminals open as main-area tabs. Select the terminal tab before typing or selecting text. Terminal input goes to its shell. Use terminal selection/copy controls or supported terminal keyboard bindings; a shortcut with no selection can be interpreted by the shell. Closing a terminal tab terminates its PTY. Explorer Bash rows show agent shell jobs and open their read-only stream tabs; these differ from interactive terminals.
## TUI
/bash opens foreground/background jobs with navigation and kill controls. A chat draft beginning with ! is a direct shell command under the documented idle conditions. /select dumps history for native terminal copying.
## Recovery
Check which tab is active before typing. Do not use a shell job stream as an interactive terminal. Help cannot inspect terminal output.
