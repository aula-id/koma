# TUI /resume

## TUI /resume
Open the session hub (live + past sessions).

The /resume command opens the session hub — a full-screen view split into live “cooking” sessions and past “history” sessions. Selecting a live session swaps the daemon client’s foreground session; selecting history loads that session into a new appended tab.

Use /help for the registered command and keyboard reference. This is a TUI slash command; the GUI uses its corresponding controls.
