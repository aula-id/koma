# Extensions and store

## GUI
Extensions opens the store and installed extension details. Browse, inspect and install explicitly. Extension panels and tools depend on the installed extension's manifest and capabilities; built-in Help cannot describe undocumented third-party behavior. Installation, loading into a session and enabling a contribution are different actions.
## TUI
/store browses the marketplace. /extension manages installed extensions; /extension use loads one into the session. Some extensions provide TUI screens.
## Recovery
Check installation status, session load state and capability requirements. Users confirm uninstall/deletion. Refer to the extension's own documentation for behavior not in the built-in catalogue.
