# Remote SSH sessions

## GUI
Remote lists saved SSH hosts and remote sessions. Configure the host and authentication, connect, then create or resume a remote session. Remote file/Git/session operations run on the selected host; App preferences and App notifications belong to this installation. Check the host indicator before working.
## TUI
/remote manages saved hosts; /new remote and /resume remote use them. CLI remote connection is also supported. A local folder path is not automatically a remote path.
## Recovery
Check SSH reachability, port, user, key selection and host availability. A disconnect does not prove the remote session stopped. Reconnect and inspect the operation result before retrying.
