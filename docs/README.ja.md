# Koma

[English](README.en.md) · [한국어](README.ko.md) · [中文](README.zh.md) · [日本語](README.ja.md) · [Bahasa Indonesia](README.id.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md)

**頭の中のアイデアを、かたちに。**

Koma は、アイデアを動くソフトウェアに変える AI コーディングワークスペースです。質問やバグ、ずっと作りたかった機能を持ち込んでください。エージェントがプロジェクトを調べ、コードを変更し、チェックを実行する様子を見ながら一緒に作業できます。

[Koma を入手](https://koma.run/#install) · [ウェブサイトを見る](https://koma.run) · [ドキュメントを読む](https://koma.run/docs)

macOS、Linux、Windows で使える無料のオープンソースです。モデル提供元は自分で選べます。提供元の料金がかかる場合があります。

## ちょっとした助けが、大きな力に

作りたいものがはっきりしている日も、どこから始めるか迷う日もあります。調査や変更、見つけたことの説明を Koma に頼んでみてください。ファイルを読み、コードを書き、チェックする過程を見守れます。

![コーディングタスクを完了した Koma エージェント](../assets/readme/chat.png)

同時に進めたいことがありますか？ Koma はサブエージェントに仕事を任せ、ジョブをバックグラウンドで実行し、セッションをまたいでプロジェクトの文脈を保持できます。

## 準備ができたら

[インストーラーを選び](https://koma.run/#install)、Koma を開いてモデルを接続してください。あとは、取り組みたいことを伝えるだけです。[ドキュメント](https://koma.run/docs)も用意しています。

チームで作業していますか？ [Koma Business](https://koma.run/biz/) は計画、チャット、ドキュメントを一つの場所にまとめます。企業は Koma Cloud を自社サーバーにデプロイできます。詳しくは [Koma ホワイトペーパー](https://koma.run/brand/whitepaper)をご覧ください。
