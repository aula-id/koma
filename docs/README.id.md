# Koma

[English](README.en.md) · [한국어](README.ko.md) · [中文](README.zh.md) · [日本語](README.ja.md) · [Bahasa Indonesia](README.id.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md)

**Wujudkan apa yang ada di pikiranmu.**

Koma adalah ruang kerja coding dengan AI untuk mengubah ide menjadi software yang bisa dijalankan. Bawa pertanyaan, bug, atau fitur yang sudah lama ingin kamu buat. Agenmu bisa menjelajahi proyek, mengubah kode, dan menjalankan pemeriksaan sambil kamu ikut bekerja.

[Dapatkan Koma](https://koma.run/#install) · [Jelajahi situs](https://koma.run) · [Baca dokumentasi](https://koma.run/docs)

Gratis dan open source untuk macOS, Linux, dan Windows. Pilih penyedia modelmu sendiri; biaya dari penyedia model mungkin berlaku.

## Sedikit bantuan bisa berarti banyak

Kadang kamu sudah tahu persis apa yang ingin dibuat. Kadang kamu hanya butuh bantuan untuk mulai. Minta Koma menyelidiki masalah, membuat perubahan, atau menjelaskan temuannya. Kamu bisa mengikuti saat Koma membaca file, menulis kode, dan menjalankan pemeriksaan.

![Agen Koma menyelesaikan tugas coding](../assets/readme/chat.png)

Ada beberapa hal yang ingin dikerjakan sekaligus? Koma bisa membagi pekerjaan ke sub-agen, menjalankan tugas di latar belakang, dan menyimpan konteks proyek antar sesi.

## Siap saat kamu siap

[Pilih installer](https://koma.run/#install), buka Koma, dan hubungkan model. Lalu ceritakan apa yang ingin kamu kerjakan. [Dokumentasi](https://koma.run/docs) siap membantumu memulai.

Bekerja bersama tim? [Koma Business](https://koma.run/biz/) menyatukan perencanaan, chat, dan dokumen. Koma Cloud tersedia untuk perusahaan yang ingin memasangnya di server sendiri. Baca selengkapnya di [whitepaper Koma](https://koma.run/brand/whitepaper).

Koma menggunakan lisensi [Apache 2.0](../LICENSE). Untuk persyaratan platform dan build dari source, lihat [panduan instalasi dan build](INSTALL_AND_BUILD.md).
