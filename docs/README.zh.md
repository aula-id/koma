# Koma

[English](README.en.md) · [한국어](README.ko.md) · [中文](README.zh.md) · [日本語](README.ja.md) · [Bahasa Indonesia](README.id.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md)

**把脑海中的想法做出来。**

Koma 是一个 AI 编程工作空间，让你的想法变成可以运行的软件。无论是一个问题、一个 bug，还是一直想做的功能，都可以交给 Koma。你可以和智能体一起工作，看它探索项目、修改代码并运行检查。

[获取 Koma](https://koma.run/#install) · [浏览网站](https://koma.run) · [阅读文档](https://koma.run/docs)

免费开源，支持 macOS、Linux 和 Windows。你可以自行选择模型服务商，服务商可能会收取费用。

## 有个帮手，事情就好办多了

有时候你知道自己想做什么，有时候只是需要一点思路。让 Koma 帮你调查问题、修改代码，或解释它的发现。它读取文件、编写代码和运行检查时，你都可以跟着看。

![Koma 智能体完成一项编程任务](../assets/readme/chat.png)

同时有好几件事要做？Koma 可以把工作交给子智能体，在后台运行任务，并在不同会话之间保留项目上下文。

## 准备好了就开始

[选择安装程序](https://koma.run/#install)，打开 Koma 并连接模型，然后告诉它你想做什么。[文档](https://koma.run/docs)会帮助你开始使用。

和团队一起工作？[Koma Business](https://koma.run/biz/) 将计划、聊天和文档放在一起。企业可以在自己的服务器上部署 Koma Cloud。更多信息请参阅 [Koma 白皮书](https://koma.run/brand/whitepaper)。

Koma 采用 [Apache 2.0](../LICENSE) 许可证。平台要求和源码构建方法请参阅[安装和构建指南](INSTALL_AND_BUILD.md)。
