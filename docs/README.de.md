# Koma

[English](README.en.md) · [한국어](README.ko.md) · [中文](README.zh.md) · [日本語](README.ja.md) · [Bahasa Indonesia](README.id.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md)

**Setz um, was du im Kopf hast.**

Koma ist ein KI-Arbeitsbereich zum Programmieren, in dem aus Ideen funktionierende Software wird. Bring eine Frage, einen Fehler oder die Funktion mit, die du schon lange bauen möchtest. Dein Agent kann das Projekt erkunden, Änderungen vornehmen und Prüfungen ausführen, während du mitarbeitest.

[Koma herunterladen](https://koma.run/#install) · [Website ansehen](https://koma.run) · [Dokumentation lesen](https://koma.run/docs)

Kostenlos und Open Source für macOS, Linux und Windows. Du wählst deinen Modellanbieter selbst; dabei können Kosten des Anbieters anfallen.

## Ein bisschen Hilfe bringt dich weiter

Manchmal weißt du genau, was du bauen möchtest. Manchmal brauchst du einen Anstoß für den Anfang. Bitte Koma, etwas zu untersuchen, eine Änderung vorzunehmen oder seine Erkenntnisse zu erklären. Du kannst verfolgen, wie Dateien gelesen, Code geschrieben und Prüfungen ausgeführt werden.

![Koma-Agent schließt eine Programmieraufgabe ab](../assets/readme/chat.png)

Mehrere Dinge gleichzeitig zu tun? Koma kann Arbeit an Subagenten verteilen, Aufgaben im Hintergrund ausführen und den Projektkontext über Sitzungen hinweg behalten.

## Mach es dir bequem

Code schreiben, zeichnen, im Web recherchieren und Änderungen verfolgen, ohne den Faden zu verlieren. Nimm das Werkzeug, das gerade zur Aufgabe passt.

## Wenn du bereit bist

[Wähle einen Installer](https://koma.run/#install), öffne Koma und verbinde ein Modell. Sag Koma anschließend, woran du arbeiten möchtest. Die [Dokumentation](https://koma.run/docs) hilft dir beim Einstieg.

Arbeitest du im Team? [Koma Business](https://koma.run/biz/) bringt Planung, Chat und Dokumente zusammen. Unternehmen können Koma Cloud auf eigenen Servern betreiben. Mehr dazu steht im [Koma-Whitepaper](https://koma.run/brand/whitepaper).

Koma steht unter der [Apache-2.0-Lizenz](../LICENSE). Plattformanforderungen und den Build aus dem Quellcode findest du in der [Installations- und Build-Anleitung](INSTALL_AND_BUILD.md).
