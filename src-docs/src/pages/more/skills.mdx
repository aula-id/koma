# Saved ways of working

A skill is a saved set of instructions, such as how your team writes a client brief. Turning one on teaches this conversation that habit.

import { Guide } from '../../components/Guide.client'
import { skillSteps } from '../../guides/more'

<Guide steps={skillSteps} />

Type `/skill`. Enter loads or unloads the row you are on.

A loaded skill applies to this conversation. It does not rewrite your other conversations.

You do not have to load skills yourself. The agent looks for a fitting skill when a task needs one, so even a very large collection does not slow it down.

:::note[If this is not what you see]
If the list is empty, no skills are installed on this computer yet. You can keep working without one.
:::
